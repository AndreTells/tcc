  \begin{abstract} 
    O presente estudo compara diferentes métodos para obter padrões de uso da
    \textit{glibc} utilizando dados de projetos do Github. São comparadas três
    maneiras distintas de realizar-se tal processo: mineração de regras de
    associação, clusterização \& um modelo probabilístico.

    Os procedimentos citados são comparados empregando métodos estatísticos.
    Divide-se a análise dos resultados entre descrição dos padrões encontrados e
    comparação entre os conjuntos de padrões encontrados.
  \end{abstract}
